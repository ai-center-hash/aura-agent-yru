จุดที่แต่ละ persona ใช้ทดสอบ

- **`normal_with_gaps`** เคสหลัก: เกณฑ์ `normal_*`, มีรอบที่ติดป้าย "ไม่แน่ใจเรื่องสิทธิ์สมัคร" (108 จำกัดรุ่นปี)
  และมีประวัติครบทุกสถานะ (ลงทะเบียนแล้ว / เช็คอินแล้วแต่ยังไม่เช็คเอาท์ / สมบูรณ์ / ยกเลิก)
- **`transfer_with_gaps`** ตรวจว่าใช้เกณฑ์ `transfer_*` (ครึ่งหนึ่งของปกติ) และเห็นรอบ 105 ที่จำกัดเฉพาะเทียบโอน
  ส่วนรอบ 108 ที่จำกัดคณะวิทยาศาสตร์ฯ ต้องไม่โผล่
- **`completed_all`** ตรวจว่าบอทไม่แนะนำกิจกรรมเพิ่มเมื่อครบเกณฑ์แล้ว (`recommend_activities` ต้องตอบว่าครบแล้ว)
- **`realistic_with_gaps`** กรอบ "ปีการศึกษา 2566" 14 หมวดตามของจริง ใช้จับปัญหาที่ fixture ตามคู่มือซ่อนไว้
  - ชื่อประเภทจริงคือ "กิจกรรมมหาวิทยาลัย" / "กิจกรรมเพื่อเสริมสร้างสมรรถนะทั่วไป" ไม่มีคำว่า "บังคับ"
    หมวดบังคับดูจาก**ชื่อหมวด** "กิจกรรมบังคับ" (บั๊กที่เจอ 2026-10-21)
  - หมวดที่เกณฑ์ชั่วโมงเป็น 0 (ชมรม) และหมวดที่เกณฑ์เทียบโอนเป็น 0/0 (จิตอาสาปี 3)
  - รอบที่จำกัดด้วย `target_student_codes` (7001 มีรหัสเรา, 7002 ไม่มี) และรอบที่ยังไม่กำหนดวัน (7004)
  - ชื่อหมวดจริงบางชื่อมีช่องว่างซ้อน คงไว้ตามจริง
  - สร้างใหม่ได้ด้วยสคริปต์ที่อ่านกรอบจริงแล้วแทนค่านักศึกษาด้วยค่าสมมติ (ไม่ commit response จริง)
